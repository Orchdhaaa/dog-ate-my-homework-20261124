One line, one dog excuse: "I was helping. Your homework had a 10-page essay in it and now it has zero pages. You're welcome." Caught red-pawed, the dog does not apologise: it reduced a ten-page essay to zero pages and expects thanks.

## Run it

```sh
node main.ts
```

`main.ts` writes the dog excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single line of 1–200 characters with no dash.
